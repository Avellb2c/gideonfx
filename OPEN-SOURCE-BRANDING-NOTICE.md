Gideon Rx uses an original, code-authored spacecraft silhouette for the web,
favicon and Agent tray identity. The asset is not derived from Gideon Rx marks,
logos, packaging or other third-party artwork.

The source bundle can still contain third-party components (for example the
Guacamole client and the external VLC runtime). Each component keeps its own
license and attribution requirements; review the corresponding notices before
redistributing a complete build.

data directories that contain `GIDEON` are intentionally preserved. They are
migration contracts, not the user-facing product identity.
