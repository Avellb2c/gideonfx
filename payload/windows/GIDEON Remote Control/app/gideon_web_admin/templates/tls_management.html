{{ 'Estado y mantenimiento en Windows' if tls_platform == 'windows' else 'Cómo aplicar sin perder acceso' }}

{% if tls_platform == 'windows' %}
  1. El instalador genera la PKI local y configura TLS 1.2/1.3.
  2. Use «Actualizar estado» para comprobar certificados, vencimiento y huellas.
  3. Para renovar o reparar, ejecute un OneClick firmado como Administrador; no se usa Certbot ni systemd.

La CA pública se puede descargar desde esta pantalla. No se exponen claves privadas.

{% else %}
  1. Valide archivos, nombres, puertos e IPs.
  2. Revise la nueva URL y aplique con contraseña + MFA.
  3. Abra esa URL, inicie sesión y confirme en menos de 5 minutos.

Si falla HTTPS, vence el plazo o el servidor reinicia antes de confirmar, se restaura la configuración previa. No se cambia la CA cliente ni se desactiva mTLS.

La verificación local no garantiza DNS ni conectividad desde Internet. Para cambios de CA/URL, prepare la actualización de agentes.

{% endif %}
