Versiones / Releases

Ciclo estable del Agent: construir la actualización operativa → publicar DRAFT → aprobar → distribución automática.

Actualizando…
Fuente única del AgentCada release estable se construye desde el mismo runtime y políticas usados por los instaladores nuevos. AgentId, sede, token y confianza Gateway se preservan durante la actualización.
Distribución estableUna release APPROVED queda disponible sólo para Agents del mismo platform/architecture. Publicar y aprobar siguen siendo acciones auditadas e independientes.
Dos capas, dos finalidadesLas releases estables son actualizaciones operativas reducidas: actualizan el runtime y conservan el VLC ya instalado. Las fuentes de terceros se custodian como Source Companion ZIP independiente, compartido por SHA-256 y nunca se envían automáticamente a los Agents.
