# Reporte de seguridad

No publiques vulnerabilidades, credenciales ni datos operativos en issues.

Para un reporte privado, contacta al mantenedor del repositorio mediante el
canal de seguridad configurado en GitHub e incluye pasos reproducibles,
impacto, versiones afectadas y una mitigación propuesta. No adjuntes claves
privadas, tokens, contraseñas, bases de datos ni archivos de producción.
